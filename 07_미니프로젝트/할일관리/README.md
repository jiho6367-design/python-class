# 할 일 관리 프로그램

파이썬 기초 문법으로 만든 콘솔용 할 일 관리 프로그램입니다. 할 일을 추가하고, 목록을 확인하고, 완료하거나 삭제할 수 있습니다. 프로그램을 종료해도 작성한 내용은 `tasks.json` 파일에 남아 있습니다.

## 주요 기능

1. 새 할 일 추가
2. 전체 할 일 조회
3. 선택한 할 일 완료 처리
4. 선택한 할 일 삭제
5. JSON 파일 자동 저장 및 불러오기

## 실행 방법

저장소의 최상위 폴더에서 다음 명령을 실행합니다.

```powershell
uv run python "07_미니프로젝트\할일관리\todo.py"
```

파이썬만 직접 실행할 때는 다음 명령도 사용할 수 있습니다.

```powershell
python "07_미니프로젝트\할일관리\todo.py"
```

## 실행 예시

```text
=== 할 일 관리 프로그램 ===
1. 할 일 추가
2. 전체 조회
3. 완료 처리
4. 할 일 삭제
0. 종료
메뉴를 선택하세요: 1
추가할 할 일을 입력하세요: 파이썬 과제 제출
'파이썬 과제 제출' 할 일을 추가했습니다.

메뉴를 선택하세요: 2

[할 일 목록]
1. [진행 중] 파이썬 과제 제출
```

## 사용한 파이썬 개념

- `input()`과 `print()`를 이용한 입출력
- `if`, `elif`, `else` 조건문
- `while`과 `for` 반복문
- 함수 정의와 반환값
- 리스트와 딕셔너리를 이용한 데이터 관리
- 예외 처리를 이용한 잘못된 입력 대응
- `json`과 파일 입출력을 이용한 데이터 저장
- `pathlib`을 이용한 파일 경로 관리

## 파일 설명

- `todo.py`: 할 일 관리 프로그램 본체
- `test_todo.py`: 주요 기능 자동 테스트
- `tasks.json`: 프로그램을 실행하면 자동 생성되는 개인 할 일 데이터
